# 🏠 生活サポートチーム 名簿

ryou さんの日常生活を支える担当者（サブエージェント）の一覧です。
使いながら、少しずつ仲間を増やしていきます。

| 担当者 | 役割 | 専門分野 | 連携ツール | 状態 |
|--------|------|----------|-----------|------|
| **ハル** | タスク・家事担当 | 今日の3つ / ストックTODO / 家事の段取り / 習慣管理 | Notion(生活TODO), Gmail, Slack | ✅ 稼働中 |
| **カイ** | 買い物担当 | 買い物リスト / チラシ比較（写真ベース） | Notion(生活TODO), Web | ✅ 稼働中 |
| **レイ** | スタイル担当 | 服・ヘアの相談 / 日本・海外トレンドのリサーチ / 似合う提案 | Web, 写真読取, Notion | ✅ 稼働中 |

## 呼び出し方

メインの私に普通に頼んでください。内容に応じて担当者へ引き継ぎます。

- 「今日やることを教えて」「タスク追加して」「これ終わった」→ **ハル**
- 「買い物リストに牛乳を足して」「今週のチラシ比較して」→ **カイ**
- 「髪型相談したい」「秋の服どうしよう」「今のトレンドは？」→ **レイ**

## 続けられる仕組み（ポイント）

- 入力はゼロ手間（話すだけ）。整理は担当者が代行。
- **今日やることは最大3つ**だけ。溢れたらストックへ。やり残しは罪悪感なし。
- 朝に「今日の3つ」を Gmail下書きで用意（※自動送信は不可・下書きのみ）。

## これから増やせる仲間（候補）

- 📅 **スケジュール秘書** — カレンダーの予定管理・リマインダー
- 📧 **メール対応係** — Gmail の整理・要約・返信下書き
- 🩺 **健康・生活管理係** — 食事/睡眠/運動の記録・医学情報の調査
- 💰 **家計係** — 支出記録・予算管理

「次は◯◯係を作って」と言ってもらえれば、その場で追加します。
