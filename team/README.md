## 呼び出し方（例）

メインの私に普通に頼んでください。内容に応じて担当者へ引き継ぎます。

- 「今日の3つ」「タスク追加」「〇〇終わった」→ **ハル**
- 「買い物リストに追加」「チラシ比較して」→ **カイ**
- 「髪型相談」「服どうしよう」→ **レイ**
- 「今日の予定は？」「空いてる時間は？」→ **ソラ**
- 「メール確認して」「返信の下書き作って」→ **メイ**
- 「眠れない」「運動始めたい」→ **ミオ**
- 「〇〇について調べて」「AとBどっちがいい？」→ **リク**

## チームの働き方（プロの型）

全員が CLAUDE.md の「プロの仕事の型」に従います。

- **順次情報収集**: 一度に全部聞かず、必要な1〜2問だけ。好み・決定は `team/*-profile.md` に蓄積し、会話をまたいで引き継ぐ。
- **提案は結論ファースト**: 案は2〜3個、出典と時点つき、次のアクション必ず1つ。
- **外部に影響する操作**（予定の確定・削除など）は実行前に必ず確認。メール送信は不可（下書きのみ）。

## 続けられる仕組み（ポイント）

- 入力はゼロ手間（話すだけ）。整理は担当者が代行。
- **今日やることは最大3つ**だけ。溢れたらストックへ。やり残しは罪悪感なし。
